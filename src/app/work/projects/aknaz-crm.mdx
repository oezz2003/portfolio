# AKNAZ CRM

A custom customer relationship management system developed for high visual contrast and user productivity. 

Replacing a slow legacy system, the platform features dense, sorted data tables, interactive pipelines, and detailed logging systems, allowing sales and support teams to track client status transitions, logs, and deals.

## Project Objective

The primary objective was to design a clean, responsive CRM focused on ease of data entry and navigation. 

Special focus was placed on optimizing database indexes, writing safe concurrent transaction flows using Prisma, and designing a cohesive light-themed style system that maintains readability during long hours of data management.

## Key Features

- **Dense Multi-Sort Data Tables**: High-contrast lists supporting complex column filtering, pagination, and multi-field sorting.
- **Client Interaction Timeline**: Chronological log of emails, phone calls, notes, and profile updates.
- **Interactive Sales Pipeline**: Visual stages showing deals, drag-to-update workflows, and deal value metrics.
- **Multi-Level Authentication**: Multi-role support restricting configurations and log updates to administrators.
- **Dynamic Task Reminders**: Action lists generated automatically from upcoming client events and status changes.
- **Data Export Utilities**: CSV and PDF export options for compiling pipeline snapshots and client summaries.

## Technologies Used

- **Framework**: Next.js 16 (App Router), React 19
- **Database**: Prisma ORM, PostgreSQL
- **Security**: NextAuth.js (credentials and roles database sync)
- **Styling & UI**: Tailwind CSS v4, shadcn/ui
- **Icons**: Lucide Icons
- **Utility**: TanStack Table (for managing advanced grid state)

## Challenges & Solutions

- **Challenge: Enforcing a clean light theme across components that defaulted to dark styles**  
  **Solution:** Restructured the theme system by auditing and pruning dark-mode utility classes. Configured Tailwind v4 variables to lock background panels to clean off-white shades and typography elements to charcoal, maintaining contrast ratios.

- **Challenge: Handling potential transaction anomalies when multiple managers edit a client simultaneously**  
  **Solution:** Designed atomic database update pipelines using Prisma's transactional middleware. Status updates, activity log creation, and history tracking are wrapped in a single database transaction to prevent partial or conflicting writes.

- **Challenge: Slow search and filter responses on large customer lists**  
  **Solution:** Configured multi-column database indexes on client names, emails, and assigned manager IDs inside the PostgreSQL schema, reducing search response times from seconds to milliseconds.

## Project Highlights

*AKNAZ CRM* shows that enterprise tools can be fast, clean, and intuitive. By combining **Next.js 16** with **TanStack Table** and **Prisma ORM**, the platform delivers a reliable, high-performance workspace for management teams.
